# Archive Downloader

I found this extension somewhere on the interwebs.
It was broken and I fixed it to run on modern
chrome/chromium browsers. It can mass-download
files in archive.org collections.

## Installation

Just download as zip and extract somewhere. Then in
chrome add it as extracted extension.

## Usage

Go to a archive.org collection, start the extension and
it will scan for files. It's a bit quirky, but does the job.
